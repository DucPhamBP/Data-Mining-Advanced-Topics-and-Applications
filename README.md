# Data-Mining-Advanced-Topics-and-Applications

Project for the **Data Mining 2** course. It consists of analyzing and processing **time series data**, employing advanced data mining and machine learning algorithms on the **Sportify dataset**.

## Focus Areas

- **Imbalanced Learning:**  
  Random Undersampling, Edited Nearest Neighbors, Tomek Links, Cluster Centroids, Random Oversampling, SMOTE, ADASYN

- **Anomaly Detection:**  
  DBSCAN, KNN, LOF, CBLOF, HBOS, LODA, Isolation Forest, Elliptic Envelope

- **Advanced Classification Methods:**  
  Logistic Regression, SVM, Ensemble Methods (Random Forest, Bagging, AdaBoost), Neural Networks (MLP), Gradient Boosting

- **Time Series Analysis:**  
  Motif and anomaly detection, clustering, shapelet-based classification, time series classification

- **AI Explainability:**  
  LIME, SHAP
