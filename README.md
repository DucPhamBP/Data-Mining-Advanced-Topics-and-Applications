# Data-Mining-Advanced-Topics-and-Applications
Project for the Data Mining 2 course at the University of Pisa. It consists in analysing and processing time series data, employing advanced data mining/machine learning algorithms on the Sportify dataset.
This analysis is focused on:
Imbalanced learning: Random Undersampling, Edited Nearst Neighbors, Tomek's Link, Cluster Centroids, Random Oversampling, SMOTE, ADASYN
Anomaly detection: DBSCAN, KNN, LOF, CBLOF, HBOS, LODA, Isolation Forest, Elliptics Envolope;
Advanced classification methods: Logistic Regression, SVM, Ensembles (Random-Forest, Bagging, Adaboost) and Neural Netoworks (MLP), Gradient Boosting;
Time series analysis: Motifs & Anomaly detection, Clustering, Shaplet-based classification, Times series classification;
AI Explaianbility: LIME, SHAP;
